# Kam Team Design SOP

This is the standard operating procedure every graphic follows in the Kam Team Graphic Designer AI. The app enforces it: each design carries its SOP stage, a checklist per stage, and an automatic brand check. The AI assistant works inside the same procedure.

```
Brief ──▶ Create ──▶ Review ──▶ Approve ──▶ Export
 goal      template    brand check  approver    right format
 audience  copy        contrast     feedback    file naming
 message   imagery     compliance               source saved
 size      logo        image rights
```

## Roles

| Role | Does |
| --- | --- |
| **Requester** (agent or marketing) | Writes the brief, gives facts (address, price, dates, DRE #). |
| **Designer** (anyone using the app, with the AI assistant) | Builds the design from a template, runs the brand check. |
| **Approver** (team lead or broker) | Checks facts and compliance, signs off. Only a person can approve; the AI never does. |

## 1. Brief

Agree on what the design must do before anyone designs it.

- [ ] **Goal written.** What should the viewer do? ("Get 20 RSVPs for Saturday's open house.")
- [ ] **Audience and channel chosen.** Who sees it, and where (Instagram feed, Story, print flyer, email…).
- [ ] **Key message and call to action written.** One message, one call to action.
- [ ] **Canvas size matches the channel.** Use a template or a size preset.

In the app: *Workflow → Brief*, or tell the AI assistant what you need and it fills in the brief.

## 2. Create

Build the design from a template, with AI help where it saves time.

- [ ] **Started from a template** or an approved layout.
- [ ] **Headline and copy final** and spelled correctly. Facts (price, address, beds/baths, dates) come from the requester, never from the AI.
- [ ] **Imagery added**: your own photo, licensed stock, or an AI image (see the rules below).
- [ ] **Kam Team logo placed** (Add → Logo). Never stretched, black or white only.

## 3. Review

Check brand, legibility and compliance before anything goes out.

- [ ] **Brand check passes.** *Workflow* shows a score and every issue; click an issue to select the element. "Fix" items must be fixed; "Check" items need a decision.
- [ ] **Text is readable.** Contrast 4.5:1 for body text, 3:1 for large headlines; nothing too small for the canvas size.
- [ ] **Compliance.** Listing ads show the agent's DRE license number and brokerage name; Equal Housing logo where required; fair housing language (describe the property, never who should live there).
- [ ] **Image rights confirmed.** No AI images of real people. No AI image presented as the real property. Virtual staging is labeled.

## 4. Approve

A second person signs off.

- [ ] **Approver named** (Workflow → Approve).
- [ ] **Feedback resolved.**

Moving to Approve or Export while the brand check shows "Fix" items asks for confirmation; moving to Export without a named approver asks too.

## 5. Export

Download in the right format and file it.

| Use | Format |
| --- | --- |
| Instagram, Facebook, LinkedIn, web | PNG (PNG @2x for retina screens) |
| Smaller file for email | JPG |
| Print (flyers, cards) | PDF (print templates are 300 DPI) |
| Vector / web embedding | SVG |
| Editing later | Source `.kamdesign.json` (Home → Import) |

- [ ] **Right format** chosen.
- [ ] **File named** `channel_campaign_date` (the app names files `design-name_YYYY-MM-DD` automatically).
- [ ] **Source saved** with the export.

## AI rules

1. AI is a helper, not a source of facts. Prices, addresses, statistics and license numbers come from people.
2. Use AI images for mood, concepts and backgrounds. Listing photos must show the real property.
3. Never generate images of real people or of a specific real home.
4. Check each AI tool's license terms before commercial use (see *AI Tools* in the app).
5. Disclose AI-generated or virtually staged imagery where MLS or platform rules require it.
6. Add headlines and text in the app, not inside AI images, so they stay sharp and on brand.
